# Alpha-Beta-Pruning


Implementation of Alpha-beta pruning, A generic algorithm to find the optimum move in the game of chess. Also, visualized via SFML.

This project was done as a C++ practice.

## Usage

<kbd>b</kbd>: Creates next moves (birth)
<kbd>p</kbd>: Finds the optimum move (pruning)
<kbd>Esc</kbd> or <kbd>q</kbd>: Quits

It create random tree with random evaluations.
